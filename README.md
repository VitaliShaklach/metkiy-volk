# Меткий волк · Sharpshooter Wolf

Ретро-тир в браузере по мотивам **Operation Wolf** (Taito, NES 1989). Наводишь прицел, стреляешь по солдатам, вертолётам и бронетехнике, освобождаешь заложников. Картинка нарочно грубая, как на NES.

**▶ Играть: https://vitalishaklach.github.io/metkiy-volk/**

Работает на компьютере (мышь), планшете и телефоне (касания). Ничего устанавливать не нужно.

## Как играть

- **Компьютер:** мышь — прицел, левая кнопка — огонь (держи — очередь), правая кнопка или Пробел — граната, P/Esc — пауза.
- **Планшет и телефон:** коснись — выстрел в эту точку, держи палец — очередь. Красная кнопка в углу — граната: нажми её, потом коснись места, куда бросить. Держи устройство горизонтально.
- Полные правила с картинками — кнопка **«? ПРАВИЛА»** в игре.

Шесть миссий на карте операции: Узел связи, Джунгли, Деревня, Склад боеприпасов, Концлагерь и Аэропорт с финальным боевым вертолётом. Порядок выбираешь сам. За каждую миссию — награда, а концовка зависит от того, сколько заложников ты спас.

Есть три уровня сложности. **Лёгкий** подходит детям: враги стреляют реже, патронов больше, нет штрафа за промахи по своим.

На iPad добавь игру на экран «Домой» (Safari → «Поделиться» → «На экран Домой»), тогда она откроется на весь экран.

## English

A retro shooting gallery inspired by Operation Wolf (NES). Aim, shoot soldiers, helicopters and armoured cars, and rescue hostages across six missions. Play at **https://vitalishaklach.github.io/metkiy-volk/** with a mouse or by touch; the language switch is in the main menu.

## О проекте

Это некоммерческий фанатский ремейк. Код, пиксель-арт, фоны, звуки и музыка сделаны с нуля, ресурсов оригинальной игры здесь нет. Operation Wolf — торговая марка Taito Corporation; проект с Taito не связан.

Чистый HTML, Canvas и JavaScript, без сборки и зависимостей. Чтобы запустить локально:

```
node tools/serve.mjs
```

и открыть http://localhost:8765. Иконки пересобираются командой `node tools/make-icons.mjs`.
